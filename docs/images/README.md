# README screenshots

These are real MenuCal screenshots from the manual checks on September 18, 2026, on macOS 26.
They use the Russian interface and are kept as PNG files without retouching.

| File | Setup |
| --- | --- |
| `calendar-light.png` | Light appearance, Regular density, full date line and red weekends |
| `calendar-dark-compact.png` | Dark appearance, Compact density, week numbers and day number menu bar icon |
| `appearance-settings.png` | Appearance pane with theme, accent and density controls |

The calendar images show different settings, not just different colours. Glass also reflects
the content behind the panel. The dark screenshot predates the final panel edge refinement
recorded in the manual checklist later that day.

When replacing screenshots, capture the running app, keep other apps and personal information
out of the frame, and check the images at the sizes used in the root README. Update the captions
if the language, density or enabled options change.
